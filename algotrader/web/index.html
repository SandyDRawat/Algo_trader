Connect an AI

Let any AI agent backtest for you.

AlgoTrader ships an MCP server. Point Claude, Cursor or your own bot at it and it can list data, read the strategy format and run backtests.

Claude Code

claude mcp add algotrader -- uv --directory /path/to/Algo_trader run python -m algotrader.mcp_server

Claude Desktop / any client

{
  "mcpServers": {
    "algotrader": {
      "command": "uv",
      "args": ["--directory", "/path/to/Algo_trader", "run",
               "python", "-m", "algotrader.mcp_server"]
    }
  }
}

Remote agents: python -m algotrader.mcp_server --http serves streamable HTTP.

Tools exposed

  • list_datasets symbols, ranges, timeframes
  • list_presets ready strategies
  • strategy_schema the rule format
  • run_backtest metrics, coaching notes, trades
